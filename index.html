Tải Video Đa Nền Tảng

Hỗ trợ tải video chất lượng cao không logo từ TikTok, Douyin, YouTube và Bilibili. Chạy trực tiếp trên Web hoặc dùng công cụ Python CLI.

📺 Bilibili (哔哩哔哩)

Tiêu đề video

👤 Tác giả ⏱️ Thời lượng 🌐 Nền tảng

Tùy chỉnh và tạo câu lệnh dòng lệnh (CLI) bằng script Python video_downloader.py để tải video chất lượng 4K/1080p, tải hàng loạt hoặc tải nguyên playlist.

Câu lệnh Terminal sẵn sàng chạy:
python video_downloader.py https://...
📥 Tải file video_downloader.py 📄 Tải file requirements.txt
1. Cài đặt môi trường Python & Thư viện ▼

Clone repo từ GitHub về máy tính và cài đặt các thư viện cần thiết:

git clone https://github.com/anh600644-cyber/Taivideo.git
cd Taivideo
pip install -r requirements.txt
2. Cài đặt FFmpeg (Ghép video & âm thanh HD) ▼

FFmpeg cần thiết để yt-dlp ghép luồng hình ảnh chất lượng cao 1080p/4K với âm thanh:

# Windows (chạy trên PowerShell Admin):
winget install FFmpeg

# MacOS:
brew install ffmpeg
3. Tải hàng loạt nhiều link từ file văn bản ▼

Tạo một file urls.txt chứa các đường link video (mỗi dòng một link), sau đó chạy:

python video_downloader.py --batch urls.txt -q 1080p
4. Tải video Bilibili yêu cầu đăng nhập ▼

Cài extension trình duyệt "Get cookies.txt LOCALLY", xuất cookies thành file cookies.txt và chạy lệnh:

python video_downloader.py https://www.bilibili.com/video/BV... --cookies cookies.txt
